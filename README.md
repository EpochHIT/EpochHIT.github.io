# EpochHIT.github.io

Personal GitHub Pages site for Bai Minghui / EpochHIT.

## Local preview

```powershell
python -m http.server 4173
```

Then open <http://localhost:4173>.

## Publish

Create a public repository named `EpochHIT.github.io`, then push this folder to the `main` branch. GitHub Pages will serve it at:

```text
https://epochhit.github.io
```
